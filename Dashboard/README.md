# Dashboard Information

This folder contains the Microsoft Power BI dashboard developed for the Marketing Funnel & Conversion Performance Analysis project.

The dashboard was created to analyze customer conversion behavior, marketing funnel performance, customer segmentation, and campaign effectiveness using a bank marketing campaign dataset.

The dashboard includes:
- Funnel overview and conversion metrics
- Customer conversion analysis
- Monthly conversion trends
- Contact frequency analysis
- Customer segmentation insights
- Campaign outcome analysis
- Interactive slicers and filters

Tools Used:
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

Dashboard Pages:
1. Funnel Overview
2. Customer Segment Analysis

Purpose of the Dashboard:
The dashboard was designed to transform raw marketing campaign data into actionable business insights that can support data-driven marketing decisions and campaign optimization strategies.
