
# Dataset Information

Dataset Used:
Bank Marketing Campaign Dataset

Source:
UCI Machine Learning Repository / Kaggle

Dataset Description:
This dataset contains bank marketing campaign information used to analyze customer conversion behavior, campaign performance, and marketing funnel effectiveness. The dataset includes customer demographic information, campaign interactions, previous campaign outcomes, and conversion status.

Data Cleaning Performed:
- Split CSV columns correctly using semicolon delimiters
- Checked for missing/null values
- Checked and removed exact duplicate rows
- Verified column data types
- Checked text consistency across categorical columns
- Preserved valid “unknown” category values for analysis

Helper Columns Created:
- Age Group
- Conversion Status
- Contact Frequency
- Campaign Outcome Group
- Call Duration Group

Purpose of Analysis:
The dataset was prepared for marketing funnel and conversion performance analysis using Microsoft Power BI.
